A robot that carries a brim-full open container should move as fast as the liquid allows. Most slosh-aware planners predict the liquid with a fitted pendulum or spring-mass model; learned predictors are an alternative. We compare the two model classes inside one time-minimising sampling-based model predictive controller (MPPI), in a small CPU-only simulation: a planar cart moves a rectangular container 1\,m, and the liquid is a reduced-order two-mode nonlinear slosh model chosen for this study, not a fluid simulation. Every controller gets one tuned scalar, its spill margin, selected by the same rule: the largest value with no spill on validation episodes. On the nominal liquid, MPC with a learned predictor that infers a latent liquid context from sensor history is spill-free at \rhval{main/learned-ctx-mpc/nominal/transport_time_s/mean:2}\,s, against \rhval{main/pendulum-mpc/nominal/transport_time_s/mean:2}\,s for the fitted pendulum and \rhval{main/spring-mass-mpc/nominal/transport_time_s/mean:2}\,s for the fitted single-mode spring-mass model (5 seeds). It is not the fastest system: a fitted two-mode spring-mass model reaches \rhval{main/two-mode-spring-mass-mpc/nominal/transport_time_s/mean:2}\,s and open-loop zero-vibration input shaping \rhval{main/zv-input-shaping/nominal/transport_time_s/mean:2}\,s. On held-out liquids with a lateral push, input shaping spills in \rhval{main/zv-input-shaping/heldout_push/spill_rate/mean:pct0} of episodes and the two-mode model in \rhval{main/two-mode-spring-mass-mpc/heldout_push/spill_rate/mean:pct0}; the learned controller spills in \rhval{main/learned-ctx-mpc/heldout_push/spill_rate/mean:pct0}, more than the slower pendulum controller (\rhval{main/pendulum-mpc/heldout_push/spill_rate/mean:pct1}) at their tuned margins, but less than the pendulum controller when both are run at the same transport time. When the ground truth is a single linear mode, the learned and pendulum controllers are indistinguishable. Sensing the liquid matters far more than which liquid sensor is used.
